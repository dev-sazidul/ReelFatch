## Migration status

The Next.js and FastAPI implementations replace Vite and NestJS. Old source/build files are removed in the migration diff. Backend startup loads `backend/.env` without overriding shell variables. The frontend environment example at `frontend/.env.example` uses `NEXT_PUBLIC_API_BASE_URL`, `NEXT_PUBLIC_SITE_URL`, and server-only `API_PROXY_TARGET`. Put frontend environment files in `frontend/` and rebuild production when those values change.

The HTTP contract retains lookup metadata, download creation/status/file endpoints, JSON error codes, and 201 for successful POSTs. Unknown frontend routes now return actual 404 responses. Metadata is server-rendered. Without a public site origin, pages render dynamically and the sitemap stays empty.

Final review fixed outbound HTTP logging that could expose CDN URLs, unsafe initial redirect schemes/ports, HEAD response-body handling, request-body buffering limits, and rate-limit dependencies running outside the event loop. The development lookup logger no longer prints JSON parser exceptions; production callers skip it.

## Authorized downloads only

Facebook uses the official Graph Video endpoint with fields `id,name,description,picture,source,format` and a Page or user Bearer token. Page token takes precedence. Never print or commit credentials.

Numeric watch/Reel/videos ids are read without fetching a page. Share/short links may resolve using public HTTPS HEAD redirects, no cookies and no HTML parsing. Graph calls require a configured token. Missing or disallowed CDN source returns `VIDEO_NOT_AVAILABLE`. One quality, “Original file,” is offered only from an allowed source; format metadata is not a list of downloadable qualities.

The homepage sample card never supplies Find Video results. YouTube, TikTok, and Instagram stay `PROVIDER_NOT_CONFIGURED`.
