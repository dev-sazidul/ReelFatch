This workspace plans ethical, editorially earned mentions. It does not change the website. No email in these files has been sent.

## What this strategy will and will not do

ReelFetch can earn trust by being listed where people already compare web tools, by publishing useful explanations of public-link downloads and copyright, and by keeping one consistent description of the product.

It will not buy links, use private blog networks, run mass directory blasts, exchange links at scale, spam comments, or invent reviews. It will not promise a ranking, a traffic number, or a domain-authority score.

Google's spam policies treat scaled link manipulation, site-reputation abuse, and expired-domain abuse as spam. The working rule here is simpler: a link is worth requesting only when the page would still help a reader if the link were removed.

## Product facts outreach must keep

Use only claims the public site already makes:

- ReelFetch checks a public video link and offers a file when that source returns one.
- Named guides exist for YouTube, Instagram, TikTok, Facebook, X, Reddit, and Pinterest.
- A link on another site may still be checked. A file is saved only when one is returned.
- Private accounts, deleted posts, and region-blocked videos are not downloaded.
- No account is required to check a link. The site does not keep a personal media library.
- Full HD appears only when the source offers it.
- ReelFetch is independent. It is not affiliated with YouTube, Meta, TikTok, X, Reddit, or Pinterest.
- People should save media they own or have permission to keep. The copyright page is https://bestdownloader.site/copyright.
- The installable experience is a browser PWA, not an App Store or APK product.

Do not say "1,000+ sites," "unlimited downloads," "always Full HD," "no tracking" (Clarity and AdSense are disclosed on the privacy page), or "official downloader."

## How authority is supposed to grow

1. **Own the honest explanation.** Platform guides, the FAQ, and the copyright page are the pages worth linking to. Comparison articles in this category often repeat feature tables. ReelFetch can be the page that explains permission, public versus private links, and why a quality is missing.
2. **Earn a small set of relevant listings.** Software and web-app directories where an editor or a logged-in submission is reviewed. Skip badge-for-backlink schemes.
3. **Pitch original explainers, not product ads.** Guest articles should teach. ReelFetch appears once, as an example, with a branded or partial-match anchor.
4. **Use communities as reputation, not as link drops.** Answer a real question. Link only when the link is the answer.
5. **Record every attempt before calling it a backlink.** The tracker separates prospects from published links. Nothing in this workspace is a verified backlink yet.

## Measurement without invented metrics

This project does not have Ahrefs, Semrush, Moz, or Majestic access. Domain authority, domain rating, referring-domain counts, and competitor backlink lists were **not measured**. Third-party roundups that print those scores were not copied into the tracker.

Until a paid index is available, use:

- Google Search Console: Links report, top linking sites, top linked pages.
- Google Search Console: queries containing "ReelFetch" and the bare domain.
- A manual visit to each URL in `BACKLINK_TRACKER.csv` before its status changes.
- `site:bestdownloader.site` and `"ReelFetch"` in Google, recorded as a spot check, not as a complete mention index.
- Server referrer logs if the host provides them. Do not log video URLs or tokens.

A row stays `Prospecting`, `Contacted`, or `Approved` until the live page shows the link. Then set `Published` and record dofollow, nofollow, or sponsored from the actual `rel` attribute. `Lost` means the link was previously verified and a later check could not find it.

## Operating cadence

Weekly, 45 minutes:

- Update tracker statuses from replies. Do not send a new batch without approval.
- Check Search Console for new linking sites.

Monthly, half a day:

- Re-open every `Published` URL.
- Run the competitor workflow in `COMPETITOR_RESEARCH.md`.
- Fill `MONTHLY_SEO_REPORT.md` for that month. Leave unknown cells blank.
- Pitch at most three publications that passed the guest-post checklist.
