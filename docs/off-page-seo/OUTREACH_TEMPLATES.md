# Outreach templates

None of these emails are approved to send. Do not connect them to a mail tool, a sequence, or a bulk sender.

Each send needs a human edit in the bracketed lines. If you cannot fill a bracket with something you saw on that site, do not send the email. Delete the brackets before sending. Keep the sender as a named person at support@reelfetch.com or a personal address that person actually reads.

Daily limit until a rhythm exists: five individually written emails, not fifty copies.

## Personalization checklist

- [ ] Their name, or a specific desk ("education editor"), not "Webmaster"
- [ ] The exact URL you are writing about
- [ ] One sentence that could only apply to that page
- [ ] The ReelFetch URL that matches that sentence
- [ ] A true description: public links, no private accounts, no quality guarantee
- [ ] No attachment they did not ask for
- [ ] No tracking domain that hides the destination
- [ ] Tracker row updated to `Contacted` on the day you send, with the source URL still the prospect page

## Recording

| Event | Tracker status |
| --- | --- |
| Page found, no email yet | Prospecting |
| Email sent by a named person | Contacted |
| They said yes, page not live | Approved |
| Live page opened and the link confirmed | Published |
| They declined, or the page is unsuitable | Lost, with the reason in Notes |
| A published link disappears on a later check | Lost |

`Approved` is not `Published`.
