# Privacy

ReelFetch Video Downloader does not run its own account system and does not collect a browsing history.

When you click Download Video, or choose Download with ReelFetch from the right-click menu, the extension opens https://bestdownloader.site/ with that one link in the `url` query parameter. The website validates the link and checks it with the existing ReelFetch downloader. The extension does not receive the file, the quality list, or your cookies.

The only saved setting is whether the popup should ask before opening the website. That setting stays in Chrome’s local extension storage on your device.

The extension does not read passwords, cookies, or authentication tokens, and it does not request access to every website you visit.

The website privacy policy is https://bestdownloader.site/privacy.
